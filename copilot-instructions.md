1. Always use `uv` for Python package management and virtual environments. When running Python scripts, use `uv run` instead of `python`. When creating virtual environments, use `uv venv` instead of `python -m venv`. When installing packages, use `uv pip install` instead of `pip install`.

2. Interpret the "^" character in a prompt to mean "most recent screenshot". Look in `D:\Pictures\Screenshots`.

3. Use LaTeX when writing math in Markdown files.

4. Use Tectonic to compile TeX files.
